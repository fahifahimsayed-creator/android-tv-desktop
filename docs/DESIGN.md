# Design

## Principles

- **The real TV is the product.** The app is a remote control and status panel; it never imitates Google
  TV's UI.
- **Calm and dark, like TV software:** large titles, rounded cards, one accent colour, generous spacing.
- **Always show a way back.** Every TV control is shown alongside its exit keys.

## Visual language

| Token | Value | Use |
|---|---|---|
| Background | `#0E1014` | window |
| Surface | `#161A21` | navigation rail |
| Card | `#1D222B`, border `#2A303B`, radius 12 | content groups |
| Accent | `#3B82F6` (hover `#5B9BFF`) | primary button, selected nav bar, toggles |
| Text | `#E8EAED`; secondary `#9AA3AF` | |
| Status | green `#22C55E` on, blue window, amber busy, red error, grey off | status dot |
| Type | Segoe UI Variable: 28 page title, 17 section, 14 body; Cascadia Mono for diagnostics | |
| Icons | Segoe Fluent Icons (Home, TV, Keyboard, Laptop, Pulse, Info) | navigation |

The title bar uses Windows 11 immersive dark mode and rounded corners (DWM attributes 20 and 33).

## Controls

- **Buttons**: rounded 8. The primary button is accent-filled; secondary buttons are card-coloured with an
  accent focus border.
- **Toggles**: switch-style check boxes, accent when on.
- **Combo boxes**: dark field with a chevron and a dark popup.
- **Shortcut boxes**: click, then press a chord. The chord is validated immediately, and duplicates or
  invalid chords are reset.
- **Busy actions** disable their button until done. Long operations never block the UI thread.

## The icon

A blue-to-violet rounded square with a white TV outline, stand and play triangle, generated by
`tools\make-icon.ps1` at 16–256 px.
